# 前端审美指南

## 设计思考（编码前四问）

1. **目的**：这个界面解决什么问题？谁用？使用时的情绪和任务压力是什么？
2. **气质**：选定一个明确风格并坚持到底——极简冷峻、复古未来、自然有机、奢华精致、玩具感、杂志编辑感、粗粝布鲁塔利主义、几何装饰艺术、柔和粉彩、工业实用主义等。
3. **约束**：技术栈、性能、响应式、可访问性要求；交付单文件还是项目代码。
4. **记忆点**：明确最让人记住的一处设计——特殊排版、空间构图、动态开场、材质背景、品牌化组件、非对称布局。

先确立概念，再精准执行。大胆不等于堆效果，克制不等于平庸。

## 字体

- 选有性格的字体组合：有表现力的标题字体搭配易读正文字体。
- 避免无思考地使用 Arial、Inter、Roboto、系统默认字体。
- 用字号层级、字距、行高建立节奏，而不是只靠加粗。

## 色彩与主题

- 用 CSS 变量维护颜色、阴影、圆角、间距等设计令牌。
- 一个主导色或主背景氛围，搭配少量锋利强调色；让颜色承载语义和品牌感。
- 避免白底紫蓝渐变卡片式模板配色。

## 动效

- 优先 CSS 动画；聚焦高影响时刻：首次进入的分层揭示、关键卡片 stagger、主要操作反馈。
- 动效要有节奏和方向感，避免所有元素同时漂浮、发光、缩放。
- 尊重 `prefers-reduced-motion`，提供降级体验。

## 空间构图

- 可用非对称、错位、重叠、破格网格、超大留白或可控高密度排版。
- 避免居中标题 + 三张卡片 + 圆角按钮的固定套路。
- 用层级、对齐、负空间、视觉重量引导视线。

## 背景与视觉细节

- 背景建立氛围：渐变网格、噪声纹理、几何图案、半透明层、戏剧性阴影、颗粒感。
- 所有装饰与主题一致，不拼接互不相关的效果。

## 反模板化清单

- 过度使用 Inter/Roboto/Arial 或系统字体
- 白底紫蓝渐变、玻璃拟态卡片、泛用 SaaS Hero 区
- 永远三列卡片、永远居中大标题、永远相同圆角按钮
- 没有场景特色、任何产品都能套的"干净但无记忆点"设计

每次根据产品、受众、场景重新选择视觉语言；亮色暗色皆可，复杂克制皆可，但必须有意图、有取舍、有完成度。

## 复杂度匹配

- 强视觉/强动效方向：可写更多 CSS 与动画细节支撑。
- 极简/高端克制方向：重点在比例、间距、字体、微妙过渡与材质精度。
- 不为炫技引入复杂抽象；当前任务需要什么，就实现什么。
